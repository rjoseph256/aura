# Mapbox token setup

Aura uses two distinct Mapbox tokens. Neither is committed to the repo.

## Runtime token (`pk.…`)

The public runtime token lives in `Aura/Resources/MapboxAccessToken`, a plain
text file holding only the `pk.…` value. It is gitignored (see `.gitignore`).

XcodeGen bundles `Resources/` into the app, so the file ships inside the app
bundle. At launch, `AuraApp.configureMapbox()` reads it and assigns it to
`MapboxOptions.accessToken`. If the file is missing or empty, the app trips an
`assertionFailure` in debug builds pointing back here.

To set it up locally, create the file with your public token:

    echo 'pk.your_public_token_here' > Aura/Resources/MapboxAccessToken

## Download token (`sk.…`)

Swift Package Manager downloads the Mapbox Maps binary SDK from
`api.mapbox.com`, which requires a secret token with the `Downloads:Read`
scope. That token lives in `~/.netrc`, not in this repo:

    machine api.mapbox.com
      login mapbox
      password sk.your_secret_download_token_here

The first `xcodegen generate` + build is slow because SPM downloads a large
binary SDK. If resolution fails with a 401/403 / authentication error, the
`~/.netrc` token is missing the `Downloads:Read` scope.

## What is committed

Only the code and config: `project.yml`, `AuraApp.swift`, `RideMapView.swift`,
and this doc. The generated `Aura.xcodeproj/` and both token locations stay out
of git.
