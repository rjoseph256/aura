# Aura

An iOS cycling app. Plan a route to a destination and get turn-by-turn voice
navigation, or start a free ride and record the track. Built with SwiftUI and the
Mapbox Maps, Navigation, and Search SDKs.

The current focus is Pittsburgh: route options are labeled Most paths, Fastest, and
Flattest, with the flattest ranked on real elevation decoded from Mapbox Terrain-RGB
tiles.

## Architecture

The code is three layers, arranged so the routing and navigation engines sit behind
protocols and can be replaced without touching the UI:

- `AuraCore` — pure Swift, no UIKit/SwiftUI/Mapbox. Models, stats, ranking, and the
  protocol seams (`RoutingProvider`, `ElevationProvider`, `GuidanceSession`).
- `AuraKit` — depends only on `AuraCore`. Observable stores and view models,
  formatting, and the plotting helpers behind the thumbnails and sparklines.
- `Aura` — the app target: SwiftUI views and the Mapbox-backed implementations.

`AuraCore` and `AuraKit` live in a local Swift package (`AuraCore/`). The Xcode
project is generated by XcodeGen from `Aura/project.yml` and is not checked in.

## Build and run

Prerequisites: Xcode 16+, [XcodeGen](https://github.com/yonaskolb/XcodeGen)
(`brew install xcodegen`), and two Mapbox tokens (see below).

```sh
# 1. Public runtime token, bundled into the app
echo 'pk.your_public_token' > Aura/Resources/MapboxAccessToken

# 2. Secret download token for the binary SDK, in ~/.netrc
#    machine api.mapbox.com
#      login mapbox
#      password sk.your_download_token

# 3. Generate the project and build
cd Aura
xcodegen generate
xcodebuild -scheme Aura -destination 'platform=iOS Simulator,name=iPhone 17' build
```

Both tokens are gitignored. The full setup, including the required token scopes, is
in [.mapbox-setup.md](.mapbox-setup.md).

## Tests

The pure layer is tested in the Swift package:

```sh
cd AuraCore && swift test
```

CI runs the same on every push (`.github/workflows/ci.yml`).
